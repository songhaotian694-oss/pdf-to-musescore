# 换行和分页

Audiveris 的 MusicXML 可以把扫描件的系统边界、页面边界作为 print new-system / new-page 输出；MuseScore 导入后可能成为 LayoutBreak line / page。原稿换了纸张、谱表尺寸或声部组合后，这些硬断点仍生效，容易造成短行、大空白或不合适的翻页。它们不是文本中的换行字符，也不能与乐章分隔混为一谈。

默认 `-LayoutMode reflow`：在新生成的 MSCZ 副本中只移除明确标记为 line、page 的 LayoutBreak，再由 MuseScore 自动排版。保留 section、nobreak 和未知类型，也保留反复、弱起、音符、文字、音色及纸张设置。不强制每行固定小节数，不因原 PDF 有几页就强制输出同样页数。

用户要求复刻原谱换行、分页或保留已设计的翻页位置时，使用 `-LayoutMode source`。这表示保留导入断点，不保证像素级复刻。给已有人工排版的工程修复音色时，不要附带执行默认重排。

`layout-assignment.json` 记录调整前后各类断点数量及所属谱表、小节／框位置；最终保存后 `layoutValidation` 核验数量和位置，失败退出码 5。旧任务缺少该报告时明确提示尚未检查，新任务不得缺失该报告。旧报告只有数量时，需在新副本重新执行布局步骤生成位置记录。

必须看全部校对页：末行是否只剩孤立小节、系统间空白是否过大、文字是否碰撞、谱面是否超边、翻页是否适合演奏。自动换行并不保证这些问题全部解决；发现问题时在副本中有依据地微调断点或间距并记录理由、重出 PDF。不得用删音符、删小节或压缩到不可读来追求页数减少。

分组与断点是不同问题：总谱和独立分谱仍分别转换，不能通过删除分页把它们串起来。布局检查也不代替内容、音色检查。
